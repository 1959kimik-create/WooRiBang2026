# 우리방 웹 앱

## 실행

최신 Chrome 또는 Edge의 PC 화면에서 이용할 수 있습니다. 화면 너비가 860px 이하인 모바일·좁은 화면에서는 PC 접속 안내가 표시됩니다. `file://`로 직접 열어도 기본 화면은 동작하지만, YouTube 임베드는 페이지 출처를 확인할 수 없어 오류 153으로 차단될 수 있습니다. YouTube 임베드를 확인하려면 프로젝트 폴더에서 `python -m http.server 8000`을 실행한 뒤 `http://localhost:8000`으로 접속하거나 HTTPS 웹 호스팅에서 실행하세요. 브라우저 음성 입력은 사용 가능한 음성 인식 서비스와 마이크 권한이 필요합니다. 자동 음성 인식이 지원되지 않거나 서비스에 연결되지 않아도 통화 마이크와 음성 송수신은 계속 켜져 있으며, 음성 인식 오류를 별도로 안내합니다.

## Supabase 설정

1. `supabase/schema.sql`은 방, 예약, 암호 해시, 참가자, 대화 데이터베이스와 기본 RLS 정책을 생성합니다.
2. `supabase/realtime.sql`은 실시간 참여·영상 신호 채널, 예약 조회, 비공개 공유 파일 저장소 및 회의 종료 시 데이터 정리 대기열을 추가합니다. 기존 프로젝트도 변경된 권한 정책을 적용하려면 이 파일을 다시 실행하세요.
3. `supabase/functions/cleanup-room`은 종료된 회의의 저장 파일과 익명 계정을 삭제하는 Edge Function입니다. `supabase/config.toml` 설정으로 JWT 검증을 유지한 채 배포합니다.
- 브라우저는 공개 anon/publishable 키만 사용합니다. `service_role`/secret key는 프런트엔드에 넣지 않습니다.

브라우저 화면에는 Supabase 예약, 실시간 채팅·참가자·자료 동기화가 연결되어 있습니다. 참가자 아이콘은 현재 Realtime Presence에 접속 중인 사용자만 표시하므로, 정상 퇴장뿐 아니라 브라우저 종료나 기기 연결 끊김으로 접속이 끊긴 경우에도 아이콘이 사라집니다. 비정상 종료 참가자의 DB 참가 기록을 임의로 지우지 않으며, 대화 메시지는 별도로 보존되어 회의록에 남습니다. 회의 화면의 카메라/마이크 버튼은 브라우저 미디어 권한으로 장치를 켜고 끄며, 영상과 음성은 WebRTC로 참가자 간 직접 전송되고 장치 ON/OFF 상태는 비공개 Supabase Realtime 채널로 공유됩니다. 마이크는 사용 가능한 입력 장치를 자동으로 검색해 연결하며, 장치가 바뀌거나 빠지면 자동 재연결을 시도합니다. 브라우저 음성 인식 서비스가 연결되면 인식 결과를 대화창에 자동 게시합니다. 서비스 연결 실패는 마이크 장치 오류와 구분해 알리고 재시도합니다. 대화가 갱신되어도 현재 채팅 스크롤 위치와 작성 중인 입력 내용은 유지됩니다. 카메라 권한과 HTTPS/localhost 접속이 필요하며, 제한적인 방화벽·네트워크에서는 TURN 중계 서버 설정이 추가로 필요할 수 있습니다. 대화 기록은 모두 좌측 정렬되고 말풍선 배경색을 사용하지 않습니다. 여러 PC의 초대 링크를 사용하려면 정적 웹 호스팅으로 앱을 배포해야 합니다. 회의 종료 시 파일과 익명 계정을 지우려면 Edge Function 배포도 필요합니다.

## 포함된 기능

- A/B/C 토론방, 30분 단위 예약표, 입장 전 참가자 이름 입력(발언자 구분)과 이미지 숫자판 암호 인증
- 예약 시각 전 입실 차단, 암호 확인, 2시간 이용과 10분 1회 연장
- 회의 화면: 참가자/장치 상태, 한국어·영어 음성 인식 언어 선택, 공유 자료 목록·확대/축소, 발언자 이름이 포함된 채팅
- 참가자 간 실시간 카메라·마이크 송수신과 상대 장치 ON/OFF 표시
- 마이크 ON 중 브라우저 음성 인식 발언을 실시간 대화 텍스트로 게시
- PDF·이미지·동영상·문서 파일 공유, 공유 파일 목록에서 개별 삭제
- 모든 참가자가 공유한 파일과 대화 대본을 묶은 ZIP 다운로드(외부 링크의 대상 파일은 제외)
- 공지사항 목록과 상세 화면

## 범위와 데이터 처리

- 익명 Supabase 세션은 브라우저 탭의 `sessionStorage`에 보관하며, 이메일·실명은 요구하지 않습니다.
- 회의 중 대화와 공유 자료는 실시간 참여자에게만 제공됩니다. 마지막 참여자가 나가면 예약·대화·공유 정보가 데이터베이스에서 제거되고, 배포된 `cleanup-room` 함수가 저장 파일과 익명 계정을 삭제합니다.
- cleanup 함수가 배포되지 않았거나 호출에 실패하면 데이터는 정리 대기열에 남습니다. 화면에서 오류를 알립니다.
- 미입장 예약의 만료 자료 및 비정상 종료 후 남은 익명 계정을 주기적으로 지우는 운영용 만료 작업은 별도 배포가 필요합니다.
- 공유 파일은 25MiB(26,214,400바이트) 이하이며 PDF, 이미지, 동영상, 문서 및 ZIP을 지원합니다. TXT/CSV, DOCX, XLS/XLSX는 브라우저에서 바로 미리 볼 수 있고, PPTX는 슬라이드 텍스트를 미리 봅니다. DOC/PPT 구형 형식은 내려받아 확인해야 합니다. Office 문서 미리보기 라이브러리는 필요할 때 CDN에서 불러오며 문서 파일 내용은 브라우저 안에서 처리합니다.
- 공유한 MP4/WebM 등 동영상 파일은 브라우저에서 재생됩니다. 직접 재생 가능한 동영상 링크와 YouTube/Vimeo 링크도 공유 화면에 표시할 수 있습니다. 외부 동영상 사이트의 재생 정책과 브라우저 지원에 따라 재생되지 않을 수 있으며, 동영상은 참가자별로 재생되고 재생 위치는 동기화되지 않습니다.
- **저장**을 선택하면 대화 대본과 공유한 파일을 `{방명}{YYYYMMDD}_{HHmm}.zip` 형식으로 다운로드합니다. 링크의 대상 파일은 ZIP에 포함되지 않습니다.
- 예약은 서버의 겹침 제약으로 동시 요청을 차단하고 암호는 bcrypt 해시로 저장합니다.
